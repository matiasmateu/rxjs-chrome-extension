# rxjs-monitor

If you are looking for `xjs-monitor`, the npm package name is `rxjs-monitor`.

`rxjs-monitor` provides RxJS operators and protocol helpers used by the RxJS DevTools extension.

## Install

```bash
npm install rxjs-monitor
```

`rxjs` is a peer dependency. Your app should provide it:

```bash
npm install rxjs
```

## Quick Start

Use `monitorRx` (or its alias `monitorRX`) in an observable pipeline:

```ts
import { interval, take } from 'rxjs';
import { monitorRX } from 'rxjs-monitor';

const stream$ = interval(250).pipe(
  take(5),
  monitorRX({
    domain: 'checkout',
    label: 'Payment Poller',
    tags: ['polling', 'payments'],
    meta: { source: 'web-app' },
  }),
);

stream$.subscribe();
```

With the extension installed, open DevTools and the `RxJS` panel to inspect emitted events.

## API

### `monitorRx(options?)` / `monitorRX(options?)`

Options:

- `instanceId`: stable ID for one monitor instance (auto-generated by default).
- `observableKey`: stable observable ID used for lane grouping.
- `label`: human-readable name shown in DevTools metadata.
- `domain`: domain key used for filtering/grouping.
- `tags`: additional filter tags.
- `meta`: extra metadata object attached to emitted events.
- `serialize`: custom serializer for `next`/`error` payloads.
- `notify`: custom transport function for emitted protocol messages.

### `safeSerialize(value, opts?)`

Utility to serialize values safely (depth/key/string limits and circular protection).

### `notifyRxjsDevtools(msg, options?)`

Sends a protocol message over `window.postMessage` using the extension transport envelope.

### Protocol utilities

```ts
import { RXJS_DEVTOOLS_FROM, isRxDevtoolsEvent } from 'rxjs-monitor/protocol';
```

- `RXJS_DEVTOOLS_FROM`: transport source marker.
- `isRxDevtoolsEvent`: runtime type guard for event payloads.

## Troubleshooting

If you see TypeScript errors mentioning both:

- `node_modules/rxjs/...`
- `node_modules/rxjs-monitor/node_modules/rxjs/...`

then your app resolved two different RxJS type instances.

Fix by ensuring one shared RxJS install:

```bash
npm dedupe
npm ls rxjs rxjs-monitor
```

and keep `rxjs` and `rxjs-monitor` on compatible versions.
